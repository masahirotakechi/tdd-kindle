# 演習問題3: バグの発見と対処

## 目標
特性化テストを書く過程で「これはバグでは？」と思う挙動を見つけたとき、
どう対処すべきかを考える。

---

## バグを見つけたときの対処フロー

```
1. 特性化テストで「今の挙動」を記録する（まだ修正しない）
        ↓
2. バグをコメントで記録する
   // バグ: SALE10 + price > 10000 のとき 15% 割引のはずが、
   //       コードの順序により到達不能になっている
        ↓
3. バグ修正のテストを別途 TDD で書く（Red → Green）
        ↓
4. 特性化テストが「安全網」として機能することを確認する
   （バグ修正が他の挙動を壊していないか）
```

---
